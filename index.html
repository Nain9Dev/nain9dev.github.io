Cómo revisarloHow to review it

  • El interruptor de tema cambia de Azul profundo a Papel. La elección se guarda en este navegador y vale para esta portada y para todas las páginas.
  • El idioma también se recuerda, tanto si lo eliges aquí como en el encabezado de cada página.
  • A 390 px el interruptor de tema vive dentro del menú.
  • Sin preferencia guardada, el sitio sigue el tema del sistema operativo.
  • Para servirlo en local, ejecuta python3 -m http.server 8000 en la raíz de esta rama y abre http://localhost:8000/. Abierto como archivo, el navegador no carga las fuentes.
  • The theme switch changes from Deep blue to Paper. The choice is stored in this browser and applies to this index and to every page.
  • The language is remembered too, whether you choose it here or in the header of any page.
  • At 390 px the theme switch lives inside the menu.
  • With no stored choice, the site follows the operating system theme.
  • To serve it locally, run python3 -m http.server 8000 at the root of this branch and open http://localhost:8000/. Opened as a file, the browser does not load the fonts.
