Sacar la IA del camino crítico de la validaciónTaking AI off the validation critical path

SituaciónSituation
La lógica de negocio llamaba directamente al proveedor de IA y la validación geométrica se ejecutaba en el mismo hilo que las peticiones HTTP. Cada cambio en la API del proveedor rompía funciones sin relación, y con carga se agotaba el pool de hilos.Business logic called the AI vendor directly and geometric validation ran on the same thread as the HTTP requests. Every change in the vendor's API broke unrelated features, and under load the thread pool ran dry.
DecisiónDecision
Clean Architecture y DDD en .NET, con el motor geométrico en un dominio puro y la IA tratada como proveedor de datos asíncrono. La validación corre en memoria con ONNX Runtime dentro de .NET.Clean Architecture and DDD in .NET, with the geometry engine in a pure domain and AI treated as an asynchronous data provider. Validation runs in memory with ONNX Runtime inside .NET.
Alternativa descartadaDiscarded alternative
Un microservicio en Python para la validación geométrica. Se descartó por el coste de serializar mallas pesadas y por la latencia de red en cada llamada.A Python microservice for geometric validation. Discarded because of the cost of serialising heavy meshes and the network latency on every call.DESCARTADADISCARDED
CompromisoTrade-off
Más memoria en los workers de .NET y más piezas que operar: bus de mensajes, workers y almacenamiento de binarios aparte.More memory on the .NET workers and more moving parts to operate: message bus, workers and separate binary storage.
ConsecuenciaConsequence
Los fallos de red salieron del camino crítico de la validación. Tiempo de validación por modelo: [METRIC].Network failures left the validation critical path. Validation time per model: [METRIC].

Particionar por tenant antes que cambiar de motorPartition by tenant rather than change engines

SituaciónSituation
Tiempos de respuesta altos en hora punta y una base de datos SQL Server que recibía todas las lecturas repetitivas. Sobre la mesa había una propuesta de migrar a NoSQL.High response times at peak hours and a SQL Server database taking every repeated read. There was a proposal on the table to move to NoSQL.
DecisiónDecision
Particionado de la base de datos por tenant y Redis como caché de primer nivel, con escrituras asíncronas por RabbitMQ.Partitioning the database by tenant and Redis as a first-level cache, with asynchronous writes over RabbitMQ.
Alternativa descartadaDiscarded alternative
Migrar a NoSQL. Se descartó porque la facturación necesita consistencia ACID.Moving to NoSQL. Discarded because billing needs ACID consistency.DESCARTADADISCARDED
CompromisoTrade-off
Invalidación de caché más compleja y monitorización distribuida, mitigadas con despliegues blue-green en Kubernetes.More complex cache invalidation and distributed monitoring, mitigated with blue-green deployments on Kubernetes.
ConsecuenciaConsequence
Las lecturas repetitivas pasaron a Redis y la base de datos quedó para escrituras y consultas transaccionales. Lecturas servidas desde caché: [METRIC]. Tiempo de respuesta en hora punta: [METRIC].Repeated reads moved to Redis and the database was left for writes and transactional queries. Reads served from cache: [METRIC]. Peak-hour response time: [METRIC].

Cómo leer estos casosHow to read these cases

Ninguna decisión de arquitectura sale gratis. Si un caso solo cuenta lo que salió bien, esconde el precio, y el precio es lo que sirve para decidir en otro proyecto.No architecture decision comes free. A case that only tells what went well hides the price, and the price is what helps you decide on another project.

Por eso cada caso trae la alternativa descartada. Sin ella no se sabe si hubo una decisión o solo costumbre.That is why each case carries the discarded alternative. Without it you cannot tell whether there was a decision or just habit.

Lo que falta a propósitoWhat is missing on purpose

Las cifras de resultado aparecen como [METRIC] hasta que tengan una fuente que se pueda citar. Los clientes no se nombran.Result figures appear as [METRIC] until they have a source that can be cited. Clients are not named.
