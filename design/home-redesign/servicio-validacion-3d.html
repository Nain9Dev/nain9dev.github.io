Servicio 01 · en detalleService 01 · in detail

Validación geométrica determinista.Deterministic geometric validation.

Qué se comprueba, en qué orden, qué devuelve y qué no hace. Esta página existe porque la diferencia entre un validador serio y un script que abre archivos está en los detalles, y los detalles se pueden leer antes de contratar.What gets checked, in what order, what it returns and what it does not do. This page exists because the difference between a serious validator and a script that opens files is in the details, and the details can be read before hiring.

El problemaThe problem

La malla mala se descubre tarde.A bad mesh is found too late.

Una malla no manifold, una normal invertida o una escala equivocada no impiden que el archivo se abra. Impiden que el proceso siguiente funcione: el motor la carga y revienta, el simulador la ignora, el presupuesto de polígonos se dispara en la pieza equivocada. A non-manifold mesh, a flipped normal or a wrong scale do not stop the file from opening. They stop the next step from working: the engine loads it and blows up, the simulator ignores it, the polygon budget explodes on the wrong piece.

Cuando ese fallo aparece en producción, el coste ya no es revisar un archivo: es parar una cadena. Validar antes cuesta milisegundos de máquina; validar después cuesta días de personas. When that failure shows up in production, the cost is no longer reviewing a file: it is stopping a chain. Validating early costs milliseconds of machine time; validating late costs days of people's time.

La regla del servicioThe rule of the service

Si una comprobación no se puede escribir como una regla que siempre da el mismo resultado, no entra en el validador. Lo que depende del criterio de una persona se queda en revisión humana, y se dice. If a check cannot be written as a rule that always gives the same result, it does not go into the validator. Anything that depends on a person's judgement stays in human review, and is stated as such.

Qué compruebaWhat it checks

Cinco familias de regla, en este orden.Five families of rule, in this order.

01

IntegridadIntegrity

Manifold, caras degeneradas, vértices sueltos, aristas con más de dos caras. Lo que hace que la malla no sea una superficie.Manifold, degenerate faces, loose vertices, edges with more than two faces. What stops the mesh from being a surface.

02

OrientaciónOrientation

Normales coherentes y hacia fuera, caras invertidas, orden de vértices. Lo que hace que se vea del revés.Coherent normals facing out, flipped faces, vertex order. What makes it render inside out.

03

Escala y unidadesScale and units

Unidad declarada contra unidad real, transformaciones sin aplicar, pivotes fuera de sitio. Lo que hace que una silla mida cuatro metros.Declared unit against real unit, unapplied transforms, misplaced pivots. What makes a chair four metres tall.

04

PresupuestoBudget

Polígonos, materiales, tamaño de textura y número de objetos contra el límite acordado para ese destino.Polygons, materials, texture size and object count against the agreed limit for that destination.

05

ConvenciónConvention

Nomenclatura, jerarquía, UVs y todo lo que el equipo haya acordado por escrito. Es la familia que cambia de un cliente a otro.Naming, hierarchy, UVs and anything the team has agreed in writing. This is the family that changes from client to client.

Qué devuelveWhat it returns

Un veredicto, no una opinión.A verdict, not an opinion.

Cada ejecución devuelve el mismo formato: el veredicto, la lista de incumplimientos con su regla y su localización en la malla, y la huella del archivo para poder repetir la comprobación. Sirve igual para una persona que para una tubería automática. Every run returns the same shape: the verdict, the list of violations with their rule and their location in the mesh, and the file fingerprint so the check can be repeated. It works the same for a person and for an automated pipeline.

Por qué importa la huellaWhy the fingerprint matters

Sin ella no se puede demostrar que dos ejecuciones miraron el mismo archivo, y sin eso «lo validamos» no significa nada. Without it you cannot prove two runs looked at the same file, and without that "we validated it" means nothing.

Servicio 01 · el contratoService 01 · the contract

Mismo archivo, mismo veredicto.Same file, same verdict.

El validador no aprende ni improvisa: ejecuta un conjunto de reglas versionado. Si el veredicto cambia, es porque cambió el archivo o cambió la versión de las reglas, y las dos cosas quedan escritas en la respuesta.The validator does not learn or improvise: it runs a versioned rule set. If the verdict changes, it is because the file changed or the rule version changed, and both are written into the response.
